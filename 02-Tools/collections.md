# 集合

目前在用的工具链。

- vscode，用了很长时间，但越来越受不了新出的功能，比如copilot只能用github版的，没法接入其他agent。还有agent mode，也没搞明白干嘛的，让整个软件很臃肿。
- vscodium，最近(2026/7)刚开始用，感觉还不错，把vscode我用不到的功能都删了，挺好的。
- zed，主力编辑器，可以通过acp接入其他agent，没有太多噪音功能，比较喜欢。这份文档就是在zed中编写。
- Intellij IDEA，现在很少打开了，只偶尔review下Java/Scala代码。感觉未来这种重型IDE全要被淘汰。

- pi coding agent。包含一个coding agent所必需的基础功能，并且可扩展性相当好。
- codex。直接yolo模式一把索。
- claude code，频繁爆出各种对中国用户甚至全世界用户的小动作，已弃用。
- opencode。感觉相比上面几个没有什么特别之处。

- ghostty。主要支持macos和linux，内置对nerd font的支持，避免有些字体不包含的显示问题。
- windows terminal。没有内置对nerd font的支持，但仍是win平台唯一指定终端。

- Sarasa Mono。最主要使用的编程字体。
- Jetbrains Mono。使用第二多的字体，也是很多网页字体的首选。
- Cascadia Mono。微软官方出品，有支持nerd font的变种，搭配windows terminal使用。
- Noto Sans CJK。谷歌和Adobe出品的东亚字体。经常作为cdn资源引入网页。

- tmux。多屏编程的解决方案。用了很多年，值得信赖。
- ncdu。命令行版的wizTree，分析各目录体积大小。
- rg,the_silver_searcher,ack。都是用来快速搜索文件内容的工具，大同小异。
- neovim，现在主要使用lazyvim配置。只用来偶尔编辑单个文件，比如.zshrc之类的。项目级别的还是会使用zed这种GUI编辑器。
- tig。命令行里的git浏览器，平常查看修改会用到。
